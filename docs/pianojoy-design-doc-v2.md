## 一、全局导航体系

### 1.1 设计原则与导航切换逻辑

导航体系分为两套完全不同的结构，根据登录状态自动切换，两套不混用：

- **未登录态**：营销网站结构，顶部横向导航，承载品牌宣传与转化入口
- **已登录态**：应用型结构，左侧固定侧边栏为唯一主导航，顶部栏精简为工具栏

切换时机：登录成功的瞬间，视觉上从"营销网站"切换为"产品应用"，对应品牌体验从"吸引"到"使用"的阶段变化。

---

### 1.2 未登录态导航栏

固定在页面顶部（sticky），高度 64px，初始透明，滚动超过 80px 后背景加模糊玻璃效果（backdrop-blur）。

**左侧：** 品牌 Logo（图文组合标），点击跳转首页

**中间（主导航菜单）：**
- 功能介绍 → Features 页
- 用户故事 → Stories 页
- 定价 → Pricing 页
- 关于我们 → About 页

**右侧：**
- 「登录」文字按钮 → 登录/注册页（默认打开登录 Tab）
- 「免费开始」主色填充按钮 → 注册页（默认打开注册 Tab）

### 1.3 已登录态顶部工具栏

高度 56px，不含页面导航菜单，背景白色或极浅灰，固定在页面顶部。

**左侧：** Logo，点击跳转 Dashboard

**中间：** 全局搜索框

- 点击后展开搜索结果面板（下拉），结果按类型分组：我的乐谱 / 收藏的乐谱 / 社区演奏 / 用户

**右侧：**
- 「📤 上传乐谱」按钮（图标+文字，次要样式）→ Upload 页
- 通知铃铛图标（有未读时显示红色数字角标）→ 点击展开通知下拉面板（见 1.6）
- 用户头像（圆形，32px，右上角显示会员徽标）→ 点击展开用户下拉菜单（见 1.5）

### P01 · 首页 Home

**触发方式：** 直接访问域名根路径 / 未登录态点击 Logo / Footer 首页链接

**页面目标：** 在 10 秒内让访客感受到「我也想弹」的情绪冲动，完成情感共鸣 → 产生行动

**SEO 目标关键词：** 成人钢琴学习 / 钢琴乐谱识别 / 在线钢琴练习

---

**页面内容结构（从上到下）：**

**① Hero 区（第一屏，视口高度 100vh）**

- 大标题（两行，大字重）：「琴悦，弹琴只为悦己」
- 副标题（一行）：「上传一张乐谱图片，三分钟后你就能开始弹」
- 主 CTA 按钮（主色填充，大）：「免费开始弹琴」→ 注册/登录页（注册 Tab）
- 次级文字链接：「已有账号？登录」→ 注册/登录页（登录 Tab）
- 背景处理方案（二选一）：
  - 方案 A：用户真实演奏的无声循环视频（手在钢琴键上弹奏，暖光），右侧叠加半透明渐变
  - 方案 B：钢琴键与乐符粒子动效（品牌主色调），纯视觉
- Hero 底部有向下滚动的箭头引导动画

**② 数据信任带（全宽横幅，浅背景）**

三组数字（带计数动画，进入视口时触发）：
- 已识别乐谱 XX 万份
- 活跃弹奏者 XX 万
- 好评率 98%

如有媒体报道：Logo 带横向滚动展示

**③ 核心流程展示（How It Works）**

三步卡片，每步：大序号 + 图标 + 标题 + 一句说明 + 步骤间流向箭头：
- Step 1「上传」：拍一张乐谱照片，或直接上传 PDF
- Step 2「识别」：AI 自动识别，生成可弹奏数字乐谱和指法
- Step 3「弹奏」：跟着琴悦练习，像有个陪练在身边

**④ 功能亮点（Feature Highlights）**

四张功能卡片，两行两列布局（移动端纵向堆叠）：
- 乐谱识别：「一张照片，变成可弹奏的数字乐谱」→ 「了解更多」跳 Features 页 #识别
- AI 指法：「不用自己摸索指法，AI 替你想好了」→ 「了解更多」跳 Features 页 #指法
- 实时陪练：「弹错了会轻柔提醒，弹对了给你鼓励」→ 「了解更多」跳 Features 页 #练习
- 社区分享：「把今天的练习发出去，找到同路人」→ 「了解更多」跳 Features 页 #社区

**⑤ 用户故事轮播（Social Proof）**

3 张卡片自动轮播（可手动切换），每张：
- 用户头像（真实照片）+ 昵称 + 城市 + 职业
- 故事引言（3-4 句，第一人称）
- 底部标注：「现在已坚持弹琴 X 天」+ 成就徽章（如「第一首完整演奏」）

轮播底部：「查看更多故事」→ Stories 页

**⑥ 订阅方案预览（简版）**

三列卡片，只展示方案名 + 核心权益（3 条）+ 价格：
- 最受欢迎（悦享）标注角标
- 每列底部 CTA：「查看完整方案」→ Pricing 页

**⑦ 最终 CTA 区（页底，深色背景）**

- 大标题：「小时候没学会的，现在开始也不晚」
- 副标题：「第一个月免费，随时可以取消」
- 按钮：「免费开始弹琴」→ 注册页

**⑧ Footer**

## 十三、版权声明机制（v2.0 新增）

### 设计原则

三个目标：**合规**（平台通过避风港原则免责）/ **低摩擦**（不破坏上传流畅性）/ **可执行**（有真实的投诉处理流程）。

---

### 各页面版权设计落点

**Upload 页（P11，UP-03 文件预览态）：**
- 版权声明勾选框（不可跳过）
- 勾选文字：「我确认我有权上传此乐谱（我是原创者、持有版权许可，或该作品版权已过期）」
- 说明小字：「上传后默认 🔒 仅自己可见。了解版权政策 →」（→ Terms 版权章节，新标签页）
- 用户不勾选时，「开始识别」按钮保持灰色不可点

**Score 页（P14，右侧操作面板）：**
- 可见性设置行：🔒 仅自己 / 🔗 有链接可访问 / 🌐 公开（悦享及以上）
- 每种状态含简短说明文字

**Shared View 页（P15，信息面板底部）：**
- 低调举报入口：「⚑ 举报版权问题」
- 点击展开内联表单（不弹新窗口）：类型单选 + 补充说明 + 提交
- 提交后 Toast：「已收到，我们将在 3 个工作日内处理」

---

### 乐谱默认可见性规则

| 来源 | 默认可见性 | 用户可修改为 |
|------|-----------|-------------|
| 用户自行上传 | 🔒 仅自己 | 仅自己 / 有链接可访问 / 公开（悦享+）|
| 通过分享链接收藏 | 与原乐谱一致（由原所有者控制）| 不可单独修改 |

---

### Terms 页版权章节要点

- **用户上传声明**：上传即声明合法持有权利，违规由用户自行承担责任
- **平台免责（避风港原则）**：收到有效版权投诉后 X 工作日内下架，不承担连带责任
- **版权投诉流程**：指定邮箱 + Shared View 举报入口；需提交版权证明 + 侵权链接 + 联系方式
- **AI 训练数据声明**：默认不使用用户乐谱训练模型；用户可选择性参与「数据贡献计划」并随时退出
- **违规处理规则**：警告 → 限制上传 30 天 → 封禁账号

## 十四、编辑器 MVP 范围（v2.0 新增）

### 定位声明

**完整创作式编辑器**：不仅限于修正 OCR 错误，支持用户从零创作和改编乐谱。

---

### MVP 必须支持（首版上线）

**基础编辑能力：**
- 选择工具（点击选中音符/小节，框选多元素）
- 音符输入：全音符 / 二分音符 / 四分音符 / 八分音符 / 十六分音符 / 三十二分音符
- 休止符输入（对应各时值）
- 音高修改：选中后键盘 ↑↓（半音）/ Shift+↑↓（八度）/ 属性面板下拉
- 升降还原号（#、b、♮）
- 删除（Delete / Backspace）
- 复制/粘贴（Ctrl+C / Ctrl+V）
- 撤销/重做（Ctrl+Z / Ctrl+Y，支持至少 50 步历史）
- 附点音符（附点开关）

**小节操作：**
- 在指定位置前/后插入空小节
- 删除小节
- 调整单一小节的局部拍号

**全局属性编辑：**
- 乐谱标题 / 作曲者 / 编曲者
- 调号（大调/小调 × 12 音名）
- 拍号（2/4、3/4、4/4、6/8 等主要拍号）
- 速度标记（BPM 数字输入）

**渲染与预览：**
- 实时 MusicXML 渲染（编辑操作后即时更新乐谱视图，无需手动刷新）
- 编辑器内 MIDI 播放预览（Space 键触发，不跳页）
- 缩放（50%-200%，步进 10%）

**保存机制：**
- 自动保存（操作后 2 秒无新操作时触发）
- 手动保存（Ctrl+S）
- 保存状态三态显示（已保存/保存中/未保存+警告）

**页面管理：**
- 多页乐谱导航
- 添加新页面
- 删除页面

---

### MVP 明确不支持（首版后置，记录在案）

| 功能 | 后置原因 | 计划迭代 |
|------|---------|---------|
| 连音线 / 圆滑线 | 跨音符关系的渲染与数据结构复杂度高 | v1.1 |
| 力度标记（p / mp / mf / f / ff）| 影响 MIDI 播放但不影响核心弹奏体验 | v1.1 |
| **多声部 / 大谱（高音谱 + 低音谱同时编辑）** | 数据模型复杂度高，但钢琴核心场景，**高优先级** | **v1.1（最优先）** |
| 速度渐变标记（rit. / accel.）| 同力度标记，非核心 | v1.2 |
| 踏板标记 | 同上 | v1.2 |
| 协作冲突可视化 | MVP 用 Last Write Wins，冲突可视化复杂度高 | v1.2 |
| 完整版本历史（逐操作快照）| MVP 只保存「完成编辑」时的版本快照 | v1.1 |
| 歌词输入 | 非核心钢琴场景 | v2.0 |
| 装饰音（颤音 / 倚音 / 回音）| 使用频率低，实现复杂 | v2.0 |
| 小连音（三连音/五连音等非标准连音）| 同上 | v2.0 |
| 离线编辑 | 需要 Service Worker + IndexedDB 架构 | v2.0 |
| 移动端触控编辑 | 触控编辑交互完全不同，移动端以练习为优先 | v2.0 |

---

### 多声部过渡降级方案（MVP 阶段）

钢琴大谱（高音谱 + 低音谱）是钢琴乐谱的标准形式，MVP 阶段不支持会直接影响大量真实乐谱的可编辑性。

**降级方案：**
OCR 识别到大谱时，将高音谱和低音谱分别保存为两个独立的单行谱对象，用户可分别在编辑器中编辑，练习时系统自动合并两轨道播放。

**用户知情说明（Review 页 + Editor 顶部 Banner）：**
「这份乐谱包含高音谱和低音谱，目前分开显示和编辑，练习时会自动合并为完整钢琴谱」

多声部完整编辑支持（同一编辑器内直接操作大谱）列为 v1.1 最高优先级功能。

---

### 协作编辑 MVP 范围（Level 1 异步协作）

**MVP 实现 Level 1 异步协作（不做实时同步）：**

- 乐谱所有者（悦享 Pro）生成「可编辑」分享链接
- 获得链接的用户打开编辑器并修改乐谱
- 保存后写入服务器（无实时 WebSocket 同步）
- 下次任何有权限的用户打开，看到最新版本
- **冲突处理**：Last Write Wins（最后保存者覆盖，简单可靠）
- 编辑器顶栏显示：「最后由 [昵称] 修改于 [时间]」
- 多人同时在线时，能看到彼此头像，但不显示实时光标（MVP 限制，顶部 Banner 提示「其他人也在编辑，建议错开时间操作，以防互相覆盖」）

**Level 2/3 实时协同（v1.2 规划）：**
- WebSocket 实时连接
- 多人实时光标显示
- OT（Operational Transformation）或 CRDT 协同模型
- 冲突可视化与手动解决

## 附录 A · 全局交互规范

### A.1 弹窗（Modal）行为规范

| 规则 | 说明 |
|------|------|
| 触发方式 | 所有弹窗必须由用户主动操作触发，禁止系统无提示主动弹出（M01 除外，属关键路由节点）|
| 关闭方式 | 支持：① 右上角「×」② ESC ③ 点击遮罩层 |
| 例外不可关闭 | M01 订单确认弹窗 / 高危操作 Step 3 完成状态 |
| 遮罩 | 半透明黑色（rgba 0,0,0,0.5），点击遮罩等同点击× |
| 动画 | 进入：中心缩放+淡入（200ms ease-out）；退出：淡出（150ms）|
| 嵌套 | 禁止弹窗内再弹弹窗，二次确认在同一弹窗内切换 Step |
| 尺寸 | 小型（确认类）360px / 中型（操作类）480px / 大型（内容类）600px；移动端全宽底部半屏 |
| 滚动锁定 | 弹窗打开时 body overflow: hidden，禁止背景滚动 |

### A.2 侧边栏（Side Panel）行为规范

| 规则 | 说明 |
|------|------|
| 推入方向 | 版本历史 M07 / 练习设置 M09 / 目录管理 M11：从右侧推入 |
| 遮罩 | 半透明（rgba 0,0,0,0.3），点击遮罩关闭 |
| 动画 | translateX(100%)→0，250ms ease-out；退出反向 |
| 主内容区 | 叠加显示，不做 push 位移 |
| 关闭 | 支持 ESC / 点击遮罩 / 面板内「完成/×」按钮 |
| 宽度 | 移动端：屏幕 85%；桌面端：各面板独立标注宽度 |

### A.3 Toast（轻提示）规范

| 类型 | 场景 | 颜色 | 停留时长 |
|------|------|------|---------|
| 成功 | 保存、收藏、复制、发布成功 | 绿色 ✓ | 3 秒 |
| 警告 | 操作未完全完成、功能受限 | 橙色 ⚠ | 4 秒 |
| 错误 | 操作失败、网络错误 | 红色 ✕ | 5 秒（含重试按钮）|
| 信息 | 中性提示（「链接已复制」）| 灰色 ℹ | 3 秒 |

位置：桌面端右下角；移动端顶部居中。最多同时显示 3 条，从下到上叠加。

### A.4 Loading 状态规范

| 场景 | 形式 |
|------|------|
| 页面初始加载 | 骨架屏（模拟页面结构灰色占位块，避免白屏跳动）|
| 按钮操作中 | 按钮内 Spinner + 文字「处理中…」+ 禁止重复点击 |
| 列表数据加载 | 骨架屏列表项（3-5 条）|
| 图片加载 | 灰色占位块，图片加载完成后淡入 |
| AI 处理（识别/点评）| 骨架屏 + 进度文字 + 可关闭（后台继续）|
| 全屏加载（编辑器/练习室）| 品牌 Logo 居中 + 进度条，超 5 秒显示错误 |

禁止：不允许用无限旋转 Spinner 作为页面级 Loading。

### A.5 表单交互规范

验证时机：blur（失焦）时触发单字段验证；提交按钮触发全量验证；不在输入过程中实时报错。

错误展示：输入框边框变红 + 下方红色提示文字（12px）。

禁用态：条件未满足的按钮灰色不可点击，悬停显示 Tooltip 说明原因。

### A.6 响应式断点规范

| 断点名 | 宽度 | 布局变化 |
|--------|------|---------|
| Mobile | < 768px | 单列，底部 Tab Bar，侧边栏隐藏为底部 Tab |
| Tablet | 768-1024px | 部分双列，侧边栏可收起 |
| Desktop | 1024-1440px | 标准双列，左侧固定侧边栏（220px）|
| Wide | > 1440px | 内容最大宽度 1200px，居中，两侧留白 |

关键页面移动端适配：

| 页面 | 移动端处理 |
|------|----------|
| Editor | 移动端不支持编辑，显示「请在电脑上使用编辑器」|
| Practice | 完整支持，键盘高度自适应，控制条简化 |
| Score | 上下布局（乐谱上，操作面板下）|
| Checkout | 上下布局（订单摘要默认折叠在顶部）|
| Library | 目录树改为顶部下拉筛选，网格变 2 列 |

## 附录 B · 全局错误处理系统

### B.1 错误分级

| 级别 | 名称 | 场景 | 展示方式 |
|------|------|------|---------|
| L1 | 字段级 | 表单输入验证失败 | 字段下红色提示文字 |
| L2 | 操作级 | 单次操作失败（保存/上传）| Toast 红色 + 重试按钮 |
| L3 | 模块级 | 页面某区块数据加载失败 | 区块内错误占位 + 重试 |
| L4 | 页面级 | 整页数据无法加载 | 全屏错误页（非白屏）|
| L5 | 系统级 | 服务器宕机/维护 | 维护页（Nginx 静态 HTML）|

### B.2 通用错误页（L4）内容

```
[品牌图标]

出了一点问题

[具体原因：「网络连接失败」或「页面加载超时」]

[「重新加载」按钮]    [「返回上一页」链接]

如果问题持续，请联系我们 →
```

### B.3 网络错误处理策略

| 网络状态 | 处理方式 |
|---------|---------|
| 完全断网 | 顶部橙色 Banner「当前无网络连接，部分功能不可用」（持续显示）|
| 网络恢复 | Banner 变绿「网络已恢复 ✓」→ 2 秒消失，自动重试失败请求 |
| 请求超时（10s）| Toast 错误 + 重试按钮 |
| 服务器 5xx | Toast「服务器暂时出了问题，请稍后重试」|
| 鉴权失效（401）| 清除登录态 → Toast「登录已过期，请重新登录」→ 跳登录页（带 returnUrl）|
| 权限不足（403）| Toast「没有权限执行此操作」（不跳页）|
| 资源不存在（404）| 跳转 404 页面 |

### B.4 支付错误（Stripe 错误码映射）

| Stripe 错误码 | 用户感知文案 |
|--------------|------------|
| card_declined | 「卡片被拒绝，请检查卡号信息或联系发卡行」|
| insufficient_funds | 「卡片余额不足，请更换一张卡」|
| expired_card | 「卡片已过期，请更换一张卡」|
| incorrect_cvc | 「安全码不正确，请检查后重试」|
| processing_error | 「支付处理出了问题，请稍后重试」|
| 其他 | 「支付失败，请重试或联系我们」|

## 附录 C · 品牌文案规范

### C.1 语气原则

琴悦的文案是**一个懂你的朋友在说话**，不是工具软件的功能说明，也不是培训机构的进步压力。

四个关键词：**温暖 / 轻盈 / 真实 / 鼓励**

| 禁止使用 | 改为 |
|---------|------|
| 错误 / 失败 / 不正确 | 「这里可以再弹一次」「还差一点」|
| 请完成以下步骤 | 「来，先做这件事」|
| 操作成功 | 「好了！」「完成了」|
| 您 | 「你」（统一，更亲近）|
| 提交 | 「发送」「保存」「完成」（具体动作）|
| 加载中 | 「正在准备」「马上就好」|
| 系统错误 | 「出了一点问题」「需要稍等一下」|
| 删除将不可恢复 | 「删除后就找不回来了」|

### C.2 权限限制文案（升级提示）

| 场景 | 不好的写法 | 琴悦的写法 |
|------|----------|----------|
| 免费用户用 AI 指法 | 「此功能需要升级」| 「让 AI 帮你想好指法，升级悦享即可」|
| 免费用户用 AI 点评 | 「高级功能，请订阅」| 「想知道这次弹得怎么样？升级后 AI 会告诉你」|
| 存储空间不足 | 「存储空间已满，无法上传」| 「地方不够了，删几张旧乐谱，或者升级获得更多空间」|
| 协作功能不可用 | 「悦享 Pro 专属功能」| 「想邀请朋友一起编辑？这是悦享 Pro 的专属」|
