# Documentation Archive

Archived documents are historical records. They should not be used as the
primary source for current product behavior or architecture.

Use archived documents when you need to understand:

- why a migration happened;
- what compatibility or cleanup choices were made during development;
- which old route, model, or UI shape was intentionally removed.

## Archive Rules

- Move completed migration plans here after the current architecture has a
  concise reference document or ADR.
- Do not add new active implementation plans directly to `archive/`.
- If an archived document conflicts with an ADR or active category document,
  the ADR or active document wins.
