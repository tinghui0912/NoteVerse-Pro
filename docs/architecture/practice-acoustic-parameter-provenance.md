# Practice Parameter Evidence

## Evidence interpretation

This inventory records current values, owners, purposes and evidence. Structural
proofs establish relationships under their stated premises. Verified model/asset
contracts bind shipped data. Synthetic tests and measurements characterize behavior
without qualifying learner intent, device latency, recognition quality or universal
memory headroom. Unqualified values describe current behavior with explicit limits.

Each row describes a currently implemented contract or derived relationship.
Qualification work belongs to that parameter's owner; equal numbers across separate
owners do not establish shared semantics. In particular W250 and MIDI grace250 are
independent, product88 does not derive raw128, and generated identity lengths do not
derive the raw-string192 budget.

See [resource proofs](practice-acoustic-resource-semantics.md),
[matching evidence](../engineering/guides/practice-timing-semantics.md),
[identity scope](practice-acoustic-identity-boundary.md) and
[measurement tooling](../engineering/guides/practice-timing-research.md).

## Qualification responsibilities

Algorithm values require learner/input/score-aligned evidence for any optimality or
generalization claim. Resource budgets require real workload, browser scheduling,
heap/GPU/GC and failure-frequency measurements. Descriptor identities establish
which implementation/assets are configured; they do not measure those properties.
Diagnostic estimates exclude object overhead, copies, queues and device allocations.
