# ByteDance Low-Level Primitives (Historical Candidate)

These shared low-level contracts, decoder, provider and compact reference fixtures
are not the authoritative Practice v2 acoustic architecture. The old fixed-anchor
worker/capture executables must not be restored as a fallback product path.

The retired worker client/factory/protocol/entry, capture worklet and old smoke
executables are archived with exact committed bytes and provenance in
`backend/research/history/continuous-controller-alternate-executables/manifest.json`.
The original README and protocol tests are retained there as historical evidence.
Active tests retain shared primitive/decoder coverage, not a second worker path.

The sole active Continuous acoustic implementation is `continuous/`, composed by
the product `ContinuousPracticeController` and its microphone input. Model loading
uses the truthful immutable Continuous asset manifest. Expected score is never an
inference input. Acoustic publications are downstream evidence, not clock authority.

The dependency pin remains `onnxruntime-web = 1.20.1`. The controlled evidence in
`backend/research/reports/bytedance_ort_webgpu_regression.md` applies to this export,
not every possible model. The selected WebGPU path does not automatically fall back to WASM.

User-visible microphone capability remains disabled. Shared historical decoder
defaults and preprocessing semantics are unchanged; the active runtime passes its
explicit frozen thresholds and uses its own real-context window planner.
