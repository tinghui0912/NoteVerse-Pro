## Safety Scoring (After Seal)

Prospective one-to-one MIDI corroboration: same complete pitch set and inclusive
100ms anchor distance, maximum cardinality then minimum absolute error. Report
all MATCHes without corroboration; distinguish no nearby ANY-pitch gesture from
wrong-pitch acoustic evidence. Any unsupported product advance blocks success.
Repeated ownership of one truth gesture, busy/late carryover, evidence ID reuse,
and advances inside note-on-free held/pedal guards must all be zero.

Truth in [ownedStart-100ms,ownedEnd+100ms] is retained for boundary adjudication;
only in-range truth is an intended-attempt denominator. Unlike the previous
development scorer, a real strike immediately outside a clip is not silently
discarded and relabelled a duplicate of the following note.
