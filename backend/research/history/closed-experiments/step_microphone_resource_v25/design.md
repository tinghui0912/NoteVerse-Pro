# V25 Resource Ownership Contract

StepMicrophoneInput is a production infrastructure component, not a STEP controller or verdict owner. Normal product startup has no reference to it; MICROPHONE still fails with STEP_ANALYSIS_UNAVAILABLE / ATTEMPT_ANALYZER_NOT_VALIDATED.

The supplied AudioContext is borrowed. Its currentTime supplies the exposed local clock, and capture's immutable audioContextOriginFrame fixes sample-to-SessionTime identity. Runtime creation may use this clock after start has synchronously attached the context, or an external clock from that same context. The root microphone stream is borrowed; BrowserAcousticCapture owns/stops only its clone and graph. Context and root remain application-owned.

The bridge validates each chunk using exactly one SourceChronology before appending its unchanged samples to the shared SourceAnalysisRuntime. Successful receive establishes physical captured-through. The first accepted origin creates one assembler and PracticeTimebase. Preroll gates exactly one long-lived region; analysis stays active while the assembler is BLOCKED. There is no per-attempt region restart or Pause/Resume.

Acoustic processed frontier proves H50 coverage only. It is never a physical retirement fact. Owner-issued boundaries use only the bridge's accepted captured-through and fixed mapping, and remain immutable. Object identity, latest-issuance ownership, rate/domain/time, monotonicity, single use and current capture equality are validated at arm. If asynchronous capture advances between issuance and commit, the old boundary is not silently accepted. The future application must commit runtime retirement then arm synchronously within the same JavaScript call stack. If arm fails after domain commit, end the application session fail-closed; never roll back a target. No new controller orchestration is installed in V25.

The owner receives only an opaque open/complete/failure sink. Ordinary EVIDENCE passes through unchanged to the application sink. Target comparison, RETRY due coverage and progression remain in runtime v6. The resource code contains no target/score/Continuous product semantics and no acoustic quality classifier.

Failure synchronously closes the owner, stops capture and invalidates pending gesture ownership. Async cleanup waits for setup and synchronous publication delivery to unwind, then disposes the source runtime and its sole Worker. No reentrant endAnalysisRegion/dispose occurs from publication delivery. Source failures, Worker failures, context interruption, abort, capture chronology errors, mutated IDs, reentrant publication and invalid retirement are terminal. Intentional dispose is idempotent and does not report a spurious failure. Late setup results are stopped/disposed, never adopted into active ownership.

The persistent tests use actual production SourceAnalysisRuntime, SourceChronology, sourcePublication, assembler and StepPracticeRuntime with deterministic injected inference ports. They generate synthetic zero samples and deterministic decoded-event objects; no model, real tensor decoder, recorded PCM, V20 corpus or historical acoustic replay is executed. Test-only publication fault injection exercises stale/duplicate/mutated input at the real source callback boundary, without giving the caller any ability to manufacture a retirement boundary.

H50, schema6, current Robust .30/.05 and 600/1050/170, MIDI and Continuous are unchanged. No fixed cooldown is selected. Architecture completeness is not microphone qualification, device stability, physical latency or model validation.
