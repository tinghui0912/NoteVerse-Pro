# Bounded Acoustic Assembly Experiment

Research only. The production foundation, STEP waiting lifecycle, MIDI and
Continuous semantics are untouched. This is not a microphone input implementation.

The committed development plan precedes scoring. Baseline 35ms is never eligible.
Only four fixed first-anchor widths (50/70/90/120ms) may be tried. No window is
extended or closed early for a target. Generic pitch-set evidence is sealed only
after the decoded analysis frontier covers the complete half-open region.

`assembler.ts` knows acoustic/source facts and generic input readiness only.
`replay.ts` binds facts to the actual product StepPracticeRuntime, not a duplicate
progression algorithm. Physical capture progresses while analysis is busy; READY
samples that source clock rather than re-arming at an analyzed frontier. Existing
decoded outputs are immutable. Robust inference is never gated by this assembler.

Development uses previously exposed sealed SMD observations. Safety selection is
lexicographic and includes boundary-confounded dangerous outcomes, separately
attributed. If no candidate passes, stop without opening a holdout or tuning more
values. A surviving candidate would require a separate prospective selected-policy
and source-disjoint MIDI-selected qualification freeze before new inference.

The raw model tensors remain transaction-local in the one product model runtime.
No expected score enters this assembler, model, decoder, or window planner.
MIDI 35ms is unrelated to this acoustic experiment. No perfect physical-strike
detector, hardware, latency SLO, scientific winner or commercial claim follows.
