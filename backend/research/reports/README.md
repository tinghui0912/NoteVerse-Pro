# Research Reports

Research outputs are local generated artifacts and are not tracked by default.
Use explicit output paths and preserve the inputs, environment and integrity
metadata needed for the intended experiment.

Compact current contracts or provenance may be committed only after review, in
the source location that owns them. Production model and runtime identities
belong to product code and asset delivery contracts.

Closed experiment evidence is available from Git history. Removing a file from
the current tree does not remove its bytes from earlier commits.
